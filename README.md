# Portafolio · Mariano Ulloa

Portafolio one-page hecho con React, Vite, TypeScript y Tailwind CSS.

Secciones: Inicio, Sobre mí, Habilidades, Proyectos y Contacto.

## Correr el proyecto

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

La carpeta `dist/` se puede publicar en Vercel o en GitHub Pages.

## Paleta (regla 60-30-10)

- 60 % café espresso `#2B2118`: fondo de Inicio, Proyectos, Contacto, encabezado y pie.
- 30 % arena `#C9B79C`: fondo de Sobre mí y Habilidades, portadas de proyectos y logo.
- 10 % café `#6B4F3A`: botones, números destacados y detalles.
- Crema `#FAF7F2`: texto sobre fondos oscuros (cuenta como blanco, fuera de la regla).
